# 🏫 Club Management System

A web-based **Club Management System** developed using **Django** to simplify the management of college clubs, members, events, and club activities.

The system provides a centralized platform where students can explore clubs, join clubs, participate in events, and manage their club-related activities efficiently.

---

## 🚀 Features

- 👤 User Registration and Login
- 🔐 Secure User Authentication
- 🏢 Club Management
- 👥 Club Member Management
- 📅 Event Management
- 📝 Event Registration
- 📢 Club Announcements
- 🎓 Student Club Participation
- 📊 Club and Event Information
- 🛠️ Admin Management through Django Admin
- 📱 Responsive Web Interface
