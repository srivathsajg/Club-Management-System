# 🏫 Club Management System

A web-based **Club Management System** developed using **Django** to manage college clubs, members, events, and club activities through a centralized platform.

## 🚀 Features

- 👤 User Registration & Login
- 🔐 User Authentication
- 🏢 Club Management
- 👥 Club Member Management
- 📅 Event Management
- 📝 Event Registration
- 📢 Club Announcements
- 🎓 Student Club Participation
- 🛠️ Admin Management using Django Admin

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript
- **Database:** SQLite
- **Tools:** Git, GitHub, VS Code

## ⚙️ Installation

```bash

2. Navigate to the Project

python -m venv venv

Windows:

python manage.py makemigrations

7. Run the Server
python manage.py runserver

👨‍💼 Admin Panel

The project uses Django Admin for managing clubs, users, members, events, and other system data.

http://127.0.0.1:8000/admin/
🎯 Objective

The main objective of this project is to provide a centralized platform for managing college clubs and their activities while making it easier for students to discover clubs, join them, and participate in events.
